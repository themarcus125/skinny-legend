# i18n — Vietnamese + English Implementation Plan (SKI-46)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every Skinny Legend surface — API, iOS app, admin console — a Vietnamese and an English face, with `users.locale` (`vi | en`, default `vi`) as the single persisted preference and Vietnamese as the source of truth for every string.

**Architecture:** One column (`users.locale`) and one write path (`PATCH /me { locale }`) carry the preference; everything else is presentation. The API keeps error `code`s as its contract and only its AI-generated `reason` text follows the locale. iOS moves 186 hardcoded Vietnamese literals into a single `Localizable.xcstrings` String Catalog whose *source language is Vietnamese* — so the existing Vietnamese literals become the keys and English is the translation — and overrides `.environment(\.locale, …)` at the root. Admin uses `next-intl` **without i18n routing**: a `locale` cookie feeds `src/i18n/request.ts`, `NextIntlClientProvider` wraps the tree, and `messages/vi.json` / `messages/en.json` hold the strings. Both clients get a lint gate (a Swift Testing test on iOS, a Node script on admin) that fails the build when a Vietnamese literal is left behind in source.

**Tech Stack:** Drizzle + Postgres + Hono + Zod (API); Swift 6 / SwiftUI / iOS 26 / XcodeGen / String Catalogs / Swift Testing (iOS); Next.js 16.3 App Router + TypeScript 6.0.3 + `next-intl@4.14.4` + Vitest + ESLint 9.39 (admin).

**Spec:** `docs/superpowers/specs/2026-09-12-v1.1-features-design.md` **section D** (binding). Sections A/B/C are covered by `docs/superpowers/plans/2026-09-12-v1.1-bounded.md`; section E by `docs/superpowers/plans/2026-09-12-push.md`.

## Global Constraints

- **Vietnamese is the source of truth.** Every new user-facing string is written in Vietnamese first; English is a translation of it. On iOS the Vietnamese text *is* the catalog key (`sourceLanguage: "vi"`). In admin, `messages/vi.json` is authored first and `messages/en.json` mirrors its key set exactly.
- **No English in `vi`, no Vietnamese in `en`.** Task 9's tables are the authority for every pair. A `vi` value that is identical to its `en` value is only allowed for proper nouns (`Skinny Legend`, `Momo`, `Google`, `Strava`).
- **Existing test counts must not drop.** Baselines at the start of this plan: API **86** (`pnpm --filter @skinny/api test`), iOS **120** (`+4` once the concurrent v1.1 video/map work lands — treat 120 as a floor, never assert an exact total), admin **107** (`pnpm --filter @skinny/admin test`). Every task ends with the suite at or above its floor.
- **Commit prefixes:** `feat(api):`, `feat(ios):`, `feat(admin):`. One commit per task, at the end of the task, after the suite is green.
- **No placeholders.** Every string in this plan is the real string. Do not invent copy that is not in a Task 9 table; if a literal turns up that Task 9 does not list, add it to the table in the same commit.
- **Enum naming:** the new Postgres enum is `user_locale`, exported as `userLocaleEnum`. It must NOT be called `locale` — the push plan (`docs/superpowers/plans/2026-09-12-push.md`, Task 2) adds a `device_locale` enum for `device_tokens.locale`, and a third bare `locale` enum would collide. The two enums are independent by design.
- **API:** `pnpm --filter @skinny/api test` needs Postgres (`docker compose up -d db`). Migrations are generated, never hand-written: `pnpm --filter @skinny/api db:generate` then `db:migrate`, and the generated SQL under `apps/api/drizzle/` is committed with the task.
- **iOS build/test:** `cd ios && xcodegen generate && xcodebuild -project SkinnyLegend.xcodeproj -scheme SkinnyLegend -destination 'platform=iOS Simulator,name=iPhone 17 Pro' test 2>&1 | grep -E "error:|warning:|Executed|TEST|BUILD"`. Zero warnings from our own code. **Only ONE agent may run `xcodegen generate` / `xcodebuild` at a time** — Tasks 2–6 are strictly sequential and must not overlap with the concurrent v1.1 iOS work.
- **iOS test files write `SkinnyLegend.Category`**, never bare `Category` — Swift Testing's `Testing` module also exports a `Category`-shaped symbol and the bare name is ambiguous inside the test target.
- **iOS: never write `if #available(iOS 26, *)`.** Deployment target is 26.0 only. Swift 6 language mode, `SWIFT_STRICT_CONCURRENCY: complete`.
- **Admin:** `pnpm --filter @skinny/admin lint|typecheck|test|build` must all pass; 0 lint warnings. Mock mode is `NEXT_PUBLIC_MOCK=1` on port 3001. The only new dependency in this whole plan is `next-intl` (pinned `^4.14.4`).
- **Admin uses no i18n routing.** No `[locale]` path segment, no middleware rewrite, no change to any existing URL. Locale comes from a cookie.
- **Error `code`s are the contract.** `apps/api/src/errors.ts` messages stay Vietnamese/English fallback text that clients are free to ignore; no client may branch on `message`.

> **Why the lint compares against the catalog rather than banning Vietnamese from source.** The catalog's source language is Vietnamese, so the Vietnamese text *is* the lookup key: `Text("Tập luyện")` is already localized and the literal correctly stays in the `.swift` file. A lint that banned Vietnamese literals outright would be unsatisfiable. The real defect this gate catches is Vietnamese copy the catalog has never seen — a string that can only ever render in Vietnamese. So the rule is: **every Vietnamese literal in `ios/SkinnyLegend/**/*.swift` must appear as a key in `Localizable.xcstrings` with a `translated` English value.**

- Produces: `AppLocale` (`.system`, `.vi`, `.en`; `AppLocale.storageKey`, `.deviceLanguageCode`, `.resolved(deviceLanguageCode:) -> AppLocale.Resolved`, `.resolved() -> AppLocale.Resolved`), `AppLocale.Resolved` (`.vi`/`.en`, `.identifier`, `.locale`), `Localized.string(_:)`, and the catalog file `ios/SkinnyLegend/Localizable.xcstrings` that Tasks 3–5 populate.

Create `ios/SkinnyLegendTests/LocalizationLintTests.swift`:

```swift
import Foundation
import Testing

/// Fails when a Vietnamese string literal in Swift source has no translated `en` entry in
/// `Localizable.xcstrings` (spec §D). The catalog's source language is Vietnamese, so a
/// migrated string still *reads* Vietnamese in source — `Text("Tập luyện")` is already a
/// `LocalizedStringKey` lookup. What must never happen is Vietnamese copy that the catalog
/// has never heard of, because that string can only ever render in Vietnamese.
///
/// `#filePath` is resolved at compile time and the Simulator shares the host filesystem, so
/// the test reads the checked-out sources and the checked-out catalog directly.
struct LocalizationLintTests {
    /// Every Vietnamese letter with a diacritic, plus đ/Đ. A literal containing any of these
    /// is Vietnamese copy by definition.
    static let vietnameseLetters = "àáảãạăằắẳẵặâầấẩẫậèéẻẽẹêềếểễệìíỉĩịòóỏõọôồốổỗộơờớởỡợùúủũụưừứửữựỳýỷỹỵđÀÁẢÃẠĂẰẮẲẴẶÂẦẤẨẪẬÈÉẺẼẸÊỀẾỂỄỆÌÍỈĨỊÒÓỎÕỌÔỒỐỔỖỘƠỜỚỞỠỢÙÚỦŨỤƯỪỨỬỮỰỲÝỶỸỴĐ"

    /// Files whose Vietnamese text is fixture data, not shipped UI copy.
    /// Nothing may be added here without a one-line reason.
    static let allowedFiles: Set<String> = [
        "Core/Mock/MockSeed.swift",   // seeded place names, AI reasons and display names — test fixtures
        "Core/Mock/MockPlace.swift",  // seeded POI names for the offline place picker
    ]

    static var sourceRoot: URL {
        URL(fileURLWithPath: #filePath)          // …/ios/SkinnyLegendTests/LocalizationLintTests.swift
            .deletingLastPathComponent()          // …/ios/SkinnyLegendTests
            .deletingLastPathComponent()          // …/ios
            .appending(path: "SkinnyLegend")
    }

    static var catalogURL: URL { sourceRoot.appending(path: "Localizable.xcstrings") }

    private struct Catalog: Decodable {
        struct Entry: Decodable {
            struct Localization: Decodable {
                struct Unit: Decodable {
                    let state: String
                    let value: String
                }
                let stringUnit: Unit?
            }
            let localizations: [String: Localization]?
        }
        let sourceLanguage: String
        let strings: [String: Entry]
    }

    static func catalog() throws -> Catalog {
        try JSONDecoder().decode(Catalog.self, from: Data(contentsOf: catalogURL))
    }

    /// Catalog keys that carry a non-empty, `translated` English value, in normalised form.
    static func translatedKeys() throws -> Set<String> {
        Set(try catalog().strings.compactMap { key, entry -> String? in
            guard let unit = entry.localizations?["en"]?.stringUnit,
                  unit.state == "translated", !unit.value.isEmpty else { return nil }
            return normalize(key)
        })
    }

    /// Collapses every Swift interpolation (`\(days)`) and every printf placeholder
    /// (`%lld`, `%@`, `%1$@`, `%.1f`) to one sentinel, so the literal written in source and
    /// the key Xcode stores in the catalog compare equal.
    static func normalize(_ text: String) -> String {
        let patterns = ["\\\\([^)]*\\)", "%[0-9]*\\$?[0-9.#+' -]*(?:lld|ld|lf|llu|lu|[dfus@])"]
        var out = text
        for pattern in patterns {
            guard let regex = try? NSRegularExpression(pattern: pattern) else { continue }
            out = regex.stringByReplacingMatches(in: out, range: NSRange(out.startIndex..., in: out), withTemplate: "\u{1}")
        }
        return out.trimmingCharacters(in: .whitespaces)
    }

    /// Every `"…"` literal containing a Vietnamese letter, on a line that is not a comment and
    /// not a `#Preview` title, paired with `file:line` for the failure message.
    static func vietnameseLiterals() throws -> [(location: String, literal: String)] {
        let fm = FileManager.default
        let escaped = NSRegularExpression.escapedPattern(for: vietnameseLetters)
        let regex = try NSRegularExpression(pattern: "\"[^\"\\n]*[\(escaped)][^\"\\n]*\"")
        var found: [(String, String)] = []
        guard let walker = fm.enumerator(at: sourceRoot, includingPropertiesForKeys: nil) else { return [] }
        for case let url as URL in walker where url.pathExtension == "swift" {
            let relative = url.path.replacingOccurrences(of: sourceRoot.path + "/", with: "")
            if allowedFiles.contains(relative) { continue }
            let text = try String(contentsOf: url, encoding: .utf8)
            for (index, line) in text.split(separator: "\n", omittingEmptySubsequences: false).enumerated() {
                let trimmed = line.trimmingCharacters(in: .whitespaces)
                if trimmed.hasPrefix("//") || trimmed.hasPrefix("*") || trimmed.hasPrefix("#Preview(") { continue }
                let ns = String(line) as NSString
                for match in regex.matches(in: String(line), range: NSRange(location: 0, length: ns.length)) {
                    let raw = ns.substring(with: match.range)
                    found.append(("\(relative):\(index + 1)", String(raw.dropFirst().dropLast())))
                }
            }
        }
        return found.sorted { $0.0 < $1.0 }
    }

    @Test func everyVietnameseLiteralIsInTheStringCatalog() throws {
        let keys = try Self.translatedKeys()
        let offenders = try Self.vietnameseLiterals()
            .filter { !keys.contains(Self.normalize($0.literal)) }
            .map { "\($0.location): \($0.literal)" }
        #expect(offenders.isEmpty, "\(offenders.count) Vietnamese literal(s) with no translated `en` entry in Localizable.xcstrings:\n\(offenders.joined(separator: "\n"))")
    }
```

```swift
import Foundation

/// The language preference the user picks in Account (spec §D). `.system` is stored locally
/// so the app keeps following the device; the *resolved* `vi`/`en` value is what goes to the
/// server in `PATCH /me { locale }`, because server-side copy (AI reasons, push) needs a
/// concrete language, not "whatever this phone is set to".
enum AppLocale: String, CaseIterable, Sendable, Hashable {
    case system
    case vi
    case en

    /// `@AppStorage` key. Namespaced so it can never collide with a Firebase or SDK default.
    static let storageKey = "com.themarcus125.skinnylegend.appLocale"

    /// A language the app actually ships.
    enum Resolved: String, Sendable, Hashable {
        case vi
        case en

        var identifier: String { rawValue }
        var locale: Locale { Locale(identifier: rawValue) }
    }

    /// `.system` follows the device; anything the app does not ship falls back to Vietnamese.
    func resolved(deviceLanguageCode: String?) -> Resolved {
        switch self {
        case .vi: .vi
        case .en: .en
        case .system: deviceLanguageCode == "en" ? .en : .vi
        }
    }

    /// The device's preferred language code, e.g. `"vi"` for `vi-VN`.
    static var deviceLanguageCode: String? {
        Locale.preferredLanguages.first.flatMap { Locale(identifier: $0).language.languageCode?.identifier }
    }

    func resolved() -> Resolved { resolved(deviceLanguageCode: Self.deviceLanguageCode) }
}
```

```swift
    /// The user's language choice. `.system` follows the device; `vi`/`en` pin it (spec §D).
    var appLocale: AppLocale = AppLocale(rawValue: UserDefaults.standard.string(forKey: AppLocale.storageKey) ?? "") ?? .system

    /// What the whole view tree runs under.
    var resolvedLocale: Locale { appLocale.resolved().locale }

    /// Applies the choice locally first (so the UI never lags behind the tap), persists it, and
    /// then tells the server — server-side copy (AI reasons, push templates) needs a concrete
    /// language even when the user picked "Hệ thống". A failed PATCH is intentionally swallowed:
    /// the local preference is the source of truth for the UI.
    func setAppLocale(_ choice: AppLocale) async {
        appLocale = choice
        UserDefaults.standard.set(choice.rawValue, forKey: AppLocale.storageKey)
        let resolved: UserDTO.Locale = choice.resolved() == .en ? .en : .vi
        guard let user = try? await api.updateMe(displayName: nil, avatarKey: nil, locale: resolved) else { return }
        if case .active = session { session = .active(user) }
        if case .pending = session { session = .pending(user) }
    }
```

```ts
import { cookies } from 'next/headers';

/** The only two languages the dashboard ships (spec §D). Vietnamese is the source of truth. */
export const LOCALES = ['vi', 'en'] as const;
export type Locale = (typeof LOCALES)[number];
export const DEFAULT_LOCALE: Locale = 'vi';

/**
 * The dashboard deliberately has NO i18n routing: no `[locale]` segment, no middleware rewrite,
 * every URL unchanged. The language lives in a plain cookie the sidebar switch writes.
 */
export const LOCALE_COOKIE = 'locale';

export function parseLocale(value: string | undefined): Locale {
  return (LOCALES as readonly string[]).includes(value ?? '') ? (value as Locale) : DEFAULT_LOCALE;
}

/** Server-side read. Never import this from a client component. */
export async function readLocale(): Promise<Locale> {
  const store = await cookies();
  return parseLocale(store.get(LOCALE_COOKIE)?.value);
}
```

```js
#!/usr/bin/env node
// Fails when Vietnamese copy is left inline in src/ instead of living in messages/*.json.
// Vietnamese is the source of truth, so vi.json is the ONLY place a Vietnamese string belongs.
import { readdirSync, readFileSync, statSync } from 'node:fs';
import { join, relative } from 'node:path';

const ROOT = new URL('..', import.meta.url).pathname;
const SRC = join(ROOT, 'src');

const VIETNAMESE = /[àáảãạăằắẳẵặâầấẩẫậèéẻẽẹêềếểễệìíỉĩịòóỏõọôồốổỗộơờớởỡợùúủũụưừứửữựỳýỷỹỵđÀÁẢÃẠĂẰẮẲẴẶÂẦẤẨẪẬÈÉẺẼẸÊỀẾỂỄỆÌÍỈĨỊÒÓỎÕỌÔỒỐỔỖỘƠỜỚỞỠỢÙÚỦŨỤƯỪỨỬỮỰỲÝỶỸỴĐ]/;

/** Files whose Vietnamese text is fixture data or a developer-facing config error. */
const ALLOWED = new Set([
  'lib/api/mock.ts',          // seeded entries, feedback and place names — fixtures, never shipped
  'lib/auth/firebase.ts',     // "Thiếu biến môi trường NEXT_PUBLIC_FIREBASE_*" — a build-time crash
  'lib/auth/gate-decision.ts' // same: missing NEXT_PUBLIC_API_BASE_URL
]);

function* walk(dir) {
  for (const name of readdirSync(dir)) {
    const path = join(dir, name);
    if (statSync(path).isDirectory()) yield* walk(path);
    else if (/\.(ts|tsx)$/.test(path)) yield path;
  }
}

const offenders = [];
for (const path of walk(SRC)) {
  const rel = relative(SRC, path);
  if (rel.includes('.test.') || rel.startsWith('test/') || ALLOWED.has(rel)) continue;
  readFileSync(path, 'utf8').split('\n').forEach((line, index) => {
    const code = line.replace(/\/\/.*$/, '').replace(/\/\*[\s\S]*?\*\//g, '');
    if (code.trim().startsWith('*')) return;
    if (VIETNAMESE.test(code)) offenders.push(`${rel}:${index + 1}: ${line.trim()}`);
  });
}

if (offenders.length > 0) {
  console.error(`lint-i18n: ${offenders.length} Vietnamese literal(s) outside messages/:\n${offenders.join('\n')}`);
  process.exit(1);
}
console.log('lint-i18n: no stray Vietnamese literals in src/');
```

Create `apps/admin/src/components/language-switch.tsx`. It writes the cookie (so the next server render picks the language up), tells the API (so the member's iOS app and push copy agree), and calls `router.refresh()` to re-render the server tree:

```tsx
'use client';

import { useTransition } from 'react';
import { useRouter } from 'next/navigation';
import { useLocale, useTranslations } from 'next-intl';
import { GlobeIcon } from 'lucide-react';
import { Button } from '@/components/ui/button';
import { LOCALE_COOKIE, LOCALES, parseLocale, type Locale } from '@/i18n/locale';
import { useApi } from '@/lib/auth/auth-context';

const LABELS: Record<Locale, string> = { vi: 'Tiếng Việt', en: 'English' };

export function LanguageSwitch() {
  const t = useTranslations('nav');
  const active = parseLocale(useLocale());
  const router = useRouter();
  const api = useApi();
  const [isPending, startTransition] = useTransition();

  const choose = (next: Locale) => {
    // One year, site-wide: the cookie is the only place the dashboard's language lives.
    document.cookie = `${LOCALE_COOKIE}=${next}; path=/; max-age=31536000; samesite=lax`;
    // Best effort — a failed PATCH must never strand the admin in the old language.
    void api.updateMe({ locale: next }).catch(() => undefined);
    startTransition(() => router.refresh());
  };

  return (
    <div className="px-2 py-1.5">
      <Button
        variant="ghost"
        size="sm"
        aria-label={t('language')}
        aria-haspopup="menu"
        disabled={isPending}
        className="w-full justify-start gap-2.5 text-secondary-foreground"
        onClick={() => choose(active === 'vi' ? 'en' : 'vi')}
      >
        <GlobeIcon aria-hidden className="size-4 shrink-0" />
        <span className="truncate">{LABELS[active]}</span>
      </Button>
      <div role="menu" className="sr-only">
        {LOCALES.map((locale) => (
          <button
            key={locale}
            type="button"
            role="menuitemradio"
            aria-checked={locale === active}
            onClick={() => choose(locale)}
          >
            {LABELS[locale]}
          </button>
        ))}
      </div>
    </div>
```
